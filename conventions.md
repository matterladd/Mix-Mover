# Conventions

Here are a short list of style conventions I use in this codebase:

Last rule takes precendence if multiple rules apply.

### General

- All data types are CamelCase (`ExampleType`)
- File and variable names are snake_case (`example_var`)

### React

- All React files are kebab-case (`example-file.tsx`)
- All React components are PascalCase (`ExampleComponent`)
- All React function and variables are camelCase (`exampleStateVar`)
